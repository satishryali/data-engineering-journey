1. Make a list of three file names. Use the same name twice. Add one more file using
   append, then predict and check the list and its length. Does the repeated name stay?

   Show the correct way to add load, then run your example.
3. Put two file records in a list. Change the item at one position, then add a new
   item using append. Explain the difference between these two changes.
