# Use the random module

Use `random` to make varied practice values or choose items from a list. Its values are generated by an algorithm; they are useful for repeatable practice data.

## Generate numbers

```python
import random

print(random.random())
print(random.randint(1, 10))
print(random.uniform(10, 100))
print(random.randrange(0, 10, 2))
```

Expected behaviour; exact values vary:

| Call | Possible result |
| --- | --- |
| `random()` | A float from `0.0` up to, but excluding, `1.0` |
| `randint(1, 10)` | An integer from 1 through 10, including both ends |
| `uniform(10, 100)` | A float between 10 and 100; floating-point rounding can affect inclusion of the end value |
| `randrange(0, 10, 2)` | One of `0, 2, 4, 6, 8`; the stop value 10 is excluded |

A float is a number represented with floating-point precision. It is not an exact decimal-money type.
The notebook repeats calls in `for i in range(100)`: that makes 100 draws, not 100 unique values.

## Choose from a list

```python
import random

categories = ["Electronics", "Clothing", "Groceries"]
print(random.choice(categories))
print(random.choices(categories, k=2))
print(random.sample(categories, k=2))
```

Expected behaviour; exact values vary:

- `choice()` returns one item.
- `choices(..., k=2)` returns a list of two picks. The same entry can be picked twice.
- `sample(..., k=2)` returns a list of two picks without selecting the same list position twice. With this list, the two category names differ.
- Sampling more items than the list contains raises `ValueError`.

## Repeat a sequence with seed

```python
import random

random.seed(10)
print([random.randint(1, 100) for i in range(3)])
random.seed(10)
print([random.randint(1, 100) for i in range(3)])
print([random.randint(1, 100) for i in range(3)])
```

Saved notebook sequence, grouped here into lists:

```text
[74, 5, 55]
[74, 5, 55]
[62, 74, 2]
```

`seed(10)` resets the generator's starting state. Repeating the same calls after the reset repeats the sequence in the same compatible Python environment. Further calls continue the sequence. A seed does not make every draw identical, and exact helper-function sequences need not stay the same across Python versions.

## Shuffle a list

```python
import random

categories = ["Electronics", "Clothing", "Groceries"]
result = random.shuffle(categories)
print(result)
print(categories)
```

Expected behaviour: `result` is `None`; `categories` holds a shuffled order. The order can occasionally be unchanged.
`shuffle()` changes the existing list. Do not replace your list with its return value.
